Section B – Generative AI Concepts
LLM – Large Language Model
Generative AI – AI that creates new content such as text, images, audio, or video.
Prompt – An instruction or question given to an AI.
System prompt – Instructions that guide how an AI should behave.
Multimodal AI – AI that can work with different types of data, such as text, images, audio, and video.
AI hallucination – When AI gives incorrect or made-up information as if it were true.
Tokens – Small pieces of text processed by an LLM.
Context window – The amount of information an AI can consider at one time.
Inference – The process of an AI model producing an answer from input.
Fine-tuning – Training an existing AI model further for a specific task or purpose.


Section C – AI for Developers & Applications
AI agent – An AI system that can perform tasks and take actions to achieve a goal.
Chatbot vs AI agent – A chatbot mainly responds to users, while an AI agent can also perform actions and complete tasks.
Tool/function calling – Allowing AI to use external tools or functions to perform tasks.
MCP – Model Context Protocol
API key – A code used to authenticate and access an AI service.
API rate limit – The maximum number of API requests allowed in a certain time.
Cursor – An AI-powered code editor.
NotebookLM – An AI tool for working with and understanding documents and notes.
Semantic search – Searching based on the meaning of the query rather than only exact words.
